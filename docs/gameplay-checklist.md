# 地板光照诊断：1.4.2-diagnostic

- 本构建用于采集现场信息，尚未修复 1.4.1 的表面光照断层。
- 关闭光影，对准萤石旁明显异常的静态原色 25G 地板，执行 `/kuayue_lighting`。命令将报告路径显示在聊天栏，文件位于游戏目录的 `logs/kuayue-lighting-时间.json`。
- 保留原测试现场。命令只采样模型和亮度，不替换地板；参考上半台阶在原位置虚拟渲染，不落地方块。

## 1.4.1 既有回归项目

- 客户端与服务端替换为 `kuayue-1.4.1.jar`，显示名称应为 `KuaYue: Standalone`，物品与方块 ID 仍为 `kuayue:`。
- 四方向各放一对同款旋转门、滑门和 C70 门，左右铰链相对。点击任意根门或上层扩展，两扇应同时开关；不同朝向、同铰链和不同款式门保持独立。手持方块仍可正常建造。
- 将双门组装进 Create 列车，停车及运行时点击两侧与上层，核对两扇动画、声音、碰撞、多客户端同步、拆解及存档重载。
- 连续铺设 25B、22、25G 等地板及跨格扩展，分别用室内灯、地板下方光源和日光检查接缝。原版平滑光照与常用光影各测一次，检查明显阶梯阴影、下方漏光和边缘缺面；车顶、Flywheel 开关及列车组装前后同样复查。服务端光传播测试未渲染光影画面。

## 1.4.0 既有回归项目

- 客户端与服务端统一为 `kuayue-1.4.0.jar`。手动挂钩、自动低速挂钩及摘钩应只播放一次原版车钩音效并出现短暂粒子；选择车钩或操作被拒绝时不播放。多人客户端核对音量、距离和重复播放。
- 同轨两列车至少一列含跨越部件，分别测试追尾、倒车接触和迎面相撞。比较空车／重车、箱内物品数量、储罐流体量的不同，观察轻车被推动或回弹，检查车辆仍在轨道、时刻表暂停、车站占用释放；手动恢复驾驶后正常运行。
- 相撞后继续接触不应每 tick 反复弹跳或播放音效；分离后再次撞击应重新响应。高相对速度碰撞检查爆炸特效与方块未受爆炸破坏。
- 纯 Create 列车之间、侧向交叉及跨维度编组继续按 Create 原生处理。头对头撞击回弹与头对头联挂不同：本版仍不支持后者的整车反向重映射。
- 多人分别乘坐、载货运行、转弯／斜坡、碰撞后摘挂钩、保存重载；核对物品和流体不变、客户端不崩溃、列车归属与间距正常。保留以下受电弓与蓝图回归。

## 1.3.1 既有回归项目

- 使用 `kuayue-1.3.1.jar`。在半高、整高车顶上检查单弓／双弓四个方向：脚座、绝缘子、固定座与弓架应整体移动，物品栏模型正常；装配、拆解、资源重载、Flywheel 开关及旧版已装配列车均复查。
- 原先崩溃的挂钩操作再测，连续挂钩／摘钩并等待运行，分别检查空车与带箱子／储罐车辆、多人客户端、货物数量、存档重载与电力学供电。

## 1.3.0 既有回归项目

- 替换为 `kuayue-1.3.0.jar`，避免与旧端口或官方同 ID 模组同时加载。核对新增“轨道、设施与建筑”物品栏。
- 原样直接打印、旋转／镜像打印及蓝图炮打印 25G 示例，检查蓝色床、端面、车窗与扩展块；连续打印并重载。`railways:link_and_pin` 两格属于外部模组，需对应依赖或自行替换。
- 五种轨道逐一测试直轨、弯轨、坡道、交叉、铺轨、车站、列车组装／运行／拆解；米轨接受米轨转向架并拒绝标准轨转向架。检查弯轨接缝、无枕外观和曲线宽度。
- 站台门上下点击及红石开关；石英板四方向；支柱上下拼接、桁架连接和占用冲突；盐矿精准采集／时运、黏土双台阶掉落、耐候钢各阶段。
- 装电力学 1.1.4，测试支柱和桁架上的接触网架／支架。半高车顶上放置单弓和双弓，检查底座贴合、选中与碰撞；染色、升降、组装、转弯、供电、拆解、重载后复查。这里检查安装底座，升降仍由电力学负责。
- 停车暂停时刻表，持扳手点击已连接端面摘钩；再依次点击两个相邻外端同向头尾车钩挂钩。低速驶近测试自动联挂。两客户端同时观察车厢、座位、货物、信号和车站状态；重载后核对列车数量、间距和归属。头对头／尾对尾应提示拒绝，当前未完成反向重映射。
- 实际制作轨道序列组装、盐、站台门、石英装饰和支柱；确认所有材料可取得且无需蓝图工作台。

## 1.2.0 检查内容

- 替换为 `kuayue-1.2.0.jar`，核对 F3／物品 ID 使用 `kuayue:`。使用只包含本轮范围内车辆部件的原版 Create 结构蓝图，验证材料识别及打印；不与同 ID 官方 Mod 同装。
- `22_end_face` 是无门端面：空手、手持普通物品及组装成列车后点击，均不应播放开关门声音。独立 `door_22` 仍应正常开关。
- 25T 及其他带门端面：四方向分别点击根方块、门的第二格与框架，检查同一扇门只切换一次；开门后检查碰撞通行、关门和移动列车上的点击。
- 22 端面贴近后从各方向快速转头，并在相邻区块／根方块处于画面外时检查端面模型；切换 Flywheel 后复查。
- 硬座首次空手和手持物品右键应直接落在一个合法座位；后续轮换、多玩家占位、Shift、扳手、存档重载、列车组装前后均需测试。染料不应把车辆座椅替换成普通 Create 座椅。
- 25B 地板分别从顶面、底面与侧面边缘补铺；结果应继承邻块朝向。验证中央点击、目标被占用、Shift 直放、扳手旋转，核对方向提示和目标轮廓与实际放置一致。车顶、裙板和扩展方块处同样复查。

# 游戏内验收清单

由用户执行。自动检查不代表这些项目已通过。

## 环境与资源

- Minecraft 1.21.1、NeoForge 21.1.264 或兼容更新版本、Create 6.0.10 及其匹配依赖。
- 启动客户端并进入测试世界，查看客货车、机车、内饰、转向架、制造材料五个物品栏。
- 检查转向架物品模型、玻璃透明度、OBJ 模型与贴图；检查中英文名称。

## 车辆方块

- 各车型抽查车板、地板、车顶、端面、车头、格栅和车底设备。
- 四个朝向放置宽车窗、多格车门和端面；检查占位、碰撞与已有方块冲突。
- 从本体与延伸部分点击、破坏方块，确认整个组件移除且只掉落一份。
- 检查旋转、左右铰链、普通门、滑门、端门、折叠梯、灯具与烟囱效果。
- 普通车板不应出现编辑水牌、编号或科技解锁界面。

## 座椅

- 硬座四人、22 型双人座和 M1 双人座分别使用多个玩家测试；检查换座与下车后重用。
- 测试 M1 座椅偏移状态；检查退出、重进世界后已占用座位与乘坐实体。
- 组装前安排多个乘客，组装、乘坐、换座、列车行驶、拆解后检查位置与座位归属。

## Create 列车

- 标准轨上放置本模组标准轨转向架，切换正反向、动力与安山岩变体。
- 在车站装配模式中用铁路机壳创建原版转向架，再用 Create 扳手循环至跨越样式；在原生车站流程中切换组内变体。
- 把合成获得的转向架物品直接放到横、纵直轨上，确认自动对齐；不兼容轨道、交叉轨或斜坡应拒绝放置。
- 检查组装、运行、转弯、轮轴及 QJ 连杆动画、车门交互、拆解和存档重载。
- 分别启用和关闭 Flywheel 可视化，检查转向架动画。
- 米轨转向架只接受对应米轨类型；本版已包含米轨轨道。
- 挂摘钩按本页 1.3.0 检查，当前范围与限制见 `docs/train-coupling.md`。

## 生存制作

- 钢材、塑料、色母、模具和电路的基础制作链。
- 工作台制作一扇门；切石机加工一种车型变体和一种转向架。
- 通过部署器、机械合成和序列组装各制作一个部件，确认不需要蓝图。
- 检查制造材料中的三类毛坯：车辆板材、内饰和转向架。

发现问题时记录模组版本、方块 ID、朝向、操作步骤与日志；模型问题附截图有助于定位。
